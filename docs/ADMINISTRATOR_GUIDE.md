# Administrator Guide

## Admin Control Center Interface
The AniVerse Admin Platform is accessible via the shield icon in the main navigation bar. It provides:
1. **Dashboard Overview**: Real-time stats on site visitors, email subscribers, active projects, and system microservice telemetry.
2. **CMS Content Manager**: Select any module (`projects`, `blogs`, `skills`, `certificates`) to perform CRUD operations, publish, or archive content.
3. **SEO & Feed Manager**: Instant generation and URL copying for `/sitemap.xml`, `/robots.txt`, and `/rss.xml`.
4. **Security & Audit Center**: Toggle Content Security Policies (CSP), view system audit logs, and configure Two-Factor Authentication (2FA).
